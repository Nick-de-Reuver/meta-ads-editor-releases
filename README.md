# Ads Editor – downloads

Hier staan de installatiebestanden van **Ads Editor**, de interne editor van Heroes of Tomorrow
om Meta-campagnes te bouwen en te publiceren.

**Installeren:** download het nieuwste `Ads-Editor-Setup-x.y.z.exe` via
[Releases → Latest](https://github.com/Nick-de-Reuver/meta-ads-editor-releases/releases/latest).

Na de installatie werkt de app zichzelf automatisch bij.

Deze repository bevat alleen installatiebestanden; de broncode staat in een privé-repository.
